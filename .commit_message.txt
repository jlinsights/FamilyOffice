✨ 브런치 스타일 타이포그래피 개선: 읽기 리듬 최적화

사용자 피드백 반영하여 브런치 스토리의 실제 타이포그래피를 정확히 구현:

**타이포그래피 최적화**
- h2 소제목: 36-48px → 24px로 축소 (읽기 부담 감소)
- h3 소제목: 24-30px → 20px로 축소 (자연스러운 계층)
- 소제목 위 간격: 64px/48px → 40px/32px (리듬 개선)
- 소제목 아래 간격: 24px/16px → 20px/16px (타이트하게)

**섹션 간격 타이트하게**
- 본문 단락 간격: 24px → 20px
- 리스트 간격: 32px → 24px
- 이미지 간격: 48px → 40px
- 섹션 구분자: 80px → 64px

**컴포넌트 간격 조정**
- Author Bio: mt-20 py-12 → mt-16 py-10
- Related Posts: mt-20 pb-24 → mt-16 pb-20
- Newsletter CTA: mt-20 → mt-16
- FAQ Section: mt-20 pb-24 → mt-16 pb-20
- References: mt-16 pt-16 → mt-12 pt-12

**히어로 이미지 최적화**
- aspect-[21/9] → aspect-video (브런치 표준)
- mb-16 → mb-12 (자연스러운 흐름)

코드 변경:
- app/insights/market-intelligence/[slug]/page.tsx 타이포그래피 전면 재조정
