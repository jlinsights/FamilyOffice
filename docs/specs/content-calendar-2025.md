## 📊 콘텐츠 유형별 가이드라인

### 화요일 - 교육/가이드 콘텐츠

```yaml
목적: 실무에 즉시 활용 가능한 지식 전달
구성:
  - 도입부 (300단어): 문제 제기 + 중요성
  - 본문 (2,000-3,000단어): 단계별 가이드
  - 실전 팁 (500단어): 즉시 실행 가능한 조언
  - 체크리스트/템플릿: 다운로드 가능한 자료
  - CTA: 관련 서비스 안내

SEO 최적화:
  - How-to 키워드 타겟팅
  - 단계별 소제목 (H2, H3)
  - 이미지/인포그래픽 3-5개
  - 내부 링크 5-7개
```

### 목요일 - 분석/사례 콘텐츠

```yaml
목적: 심층 인사이트와 실제 적용 사례 제공
구성:
  - 도입부 (200단어): 핵심 인사이트 요약
  - 배경 설명 (500단어): 상황과 도전과제
  - 분석/사례 (1,500-2,000단어): 상세 분석
  - 교훈/시사점 (500단어): 핵심 포인트
  - CTA: 맞춤 상담 유도

SEO 최적화:
  - 사례/분석 키워드
  - 데이터/차트 활용
  - 전문가 인용
  - 관련 콘텐츠 추천
```

## 📈 성과 측정 지표

### 주요 KPI

- **트래픽**: 글당 평균 1,000+ 페이지뷰 (3개월 내)
- **체류시간**: 평균 5분 이상
- **뉴스레터 전환**: 방문자의 15% 이상
- **상담 전환**: 방문자의 2% 이상

### A/B 테스트 항목

- 제목 형식 (숫자 vs 질문 vs 선언)
- CTA 위치 (상단 vs 중간 vs 하단)
- 콘텐츠 길이 (2,000 vs 3,000 vs 4,000 단어)
- 이미지 스타일 (인포그래픽 vs 차트 vs 일러스트)
