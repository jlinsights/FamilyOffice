## 🎯 구현된 기능

### 1. 상속세 계산 엔진

**파일**: `components/inheritance-tax-calculator.tsx`

#### 입력 항목

```typescript
// 자산
- 부동산 (원)
- 현금 및 예금 (원)
- 주식 및 펀드 (원)
- 기타 자산 (원)

// 부채
- 부채 (원)
- 장례비용 (원)

// 가족 구성
- 배우자 유무
- 자녀 수 (명)
```

#### 계산 로직 (2025년 세법 기준)

**1단계: 순자산 계산**

```
순자산 = (부동산 + 현금 + 주식 + 기타자산) - (부채 + 장례비용)
```

**2단계: 공제 계산**

```typescript
배우자 공제: Math.min(Math.max(5억, 순자산 * 50%), 30억)
자녀 공제: 자녀수 × 5천만원
기초 공제: 2억원
총 공제액 = 배우자공제 + 자녀공제 + 기초공제
```

**3단계: 과세표준 계산**

```
과세표준 = 순자산 - 총공제액
```

**4단계: 상속세 계산 (누진세율)**
| 과세표준 | 세율 | 누진공제 |
|---------|------|---------|
| 1억 이하 | 10% | - |
| 5억 이하 | 20% | 1천만원 |
| 10억 이하 | 30% | 6천만원 |
| 30억 이하 | 40% | 1.6억원 |
| 30억 초과 | 50% | 4.6억원 |

**5단계: 최종 납부세액**

```
최종 납부세액 = 산출세액 - 세액공제
실효세율 = (최종 납부세액 / 순자산) × 100
```


## 📝 학습 및 개선 사항

### 구현 중 발견한 인사이트

#### 1. 세법 복잡도

상속세 계산은 단순 누진세율 적용이 아니라, 다양한 공제 항목과 특례가 존재합니다:

- 가업상속공제 (최대 500억)
- 금융재산공제 (순금융재산의 20%, 최대 2억)
- 동거주택 상속공제 (최대 6억)
- 재해손실공제 등

**현재 구현**: 기본공제 + 배우자공제 + 자녀공제 (간이 계산)
**향후 개선**: 추가 공제 항목 선택 옵션 제공

#### 2. 사용자 기대치 관리

"자동 계산기"라는 이름 때문에 100% 정확한 세액을 기대할 수 있습니다.

**해결책**:

- "간이 계산 방식" 명시
- "전문가 상담 필요" 고지
- "실제 세액과 차이 있을 수 있음" 경고
- FAQ에서 정확도 설명

#### 3. 모바일 UX 중요성

한국 사용자의 70% 이상이 모바일에서 검색합니다.

**최적화**:

- 입력 필드 크기 확대 (터치 최적화)
- 숫자 키패드 자동 활성화 (type="number")
- 세로 스크롤 최소화
