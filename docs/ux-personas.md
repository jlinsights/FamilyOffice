# User Personas for FamilyOffice Asset Management System

## 1. 김철수 (Family Principal) - Primary User

**Age:** 52 | **Role:** Company CEO, Family Wealth Owner | **Tech Savvy:** Medium

### Goals & Motivations

- Monitor family wealth performance across all investments
- Make informed decisions about asset allocation
- Ensure proper succession planning for next generation
- Maintain privacy and security of financial information

### Pain Points

- Complex financial data overwhelming
- Needs simplified, executive-level dashboards
- Requires mobile access for busy schedule
- Wants real-time alerts for significant changes

### User Journey

```
Login → Dashboard Overview → Portfolio Performance →
Investment Details → Risk Assessment → Action Items
```

### Technology Preferences

- Prefers mobile-first experience
- Values simplicity over complexity
- Needs one-click access to key metrics
- Expects bank-level security

### Key Metrics

- Portfolio performance YoY
- Asset allocation balance
- Risk exposure levels
- Cash flow projections

## Persona-Based Design Principles

### For Family Principals (김철수)

- **Simplicity First**: Clean, uncluttered interfaces
- **Mobile Optimization**: Responsive design for on-the-go access
- **Executive Dashboard**: High-level summaries with drill-down capability
- **Security Emphasis**: Visible security indicators and controls

### For Investment Advisors (박영희)

- **Efficiency Focus**: Keyboard shortcuts and batch operations
- **Advanced Analytics**: Sophisticated charting and analysis tools
- **Multi-Client Management**: Seamless account switching
- **Professional Reporting**: Customizable, branded reports

### For Administrative Staff (이민호)

- **Error Prevention**: Real-time validation and confirmation dialogs
- **Bulk Operations**: Efficient mass data processing
- **Workflow Optimization**: Streamlined task completion paths
- **Quality Assurance**: Built-in verification and audit trails

### For External Consultants (최광수)

- **Controlled Access**: Role-based permissions and time limits
- **Specialized Views**: Focused data relevant to expertise area
- **Secure Collaboration**: Encrypted communication and file sharing
- **Professional Output**: High-quality, branded deliverables

## Cross-Persona Requirements

### Universal Needs

- **Accessibility**: WCAG 2.1 AA compliance for all users
- **Performance**: Sub-2-second load times for critical functions
- **Security**: Multi-factor authentication and audit logging
- **Reliability**: 99.9% uptime with graceful error handling

### Shared User Flows

- **Authentication**: Secure, user-friendly login process
- **Navigation**: Intuitive, context-aware menu systems
- **Data Export**: Flexible export options for various formats
- **Help & Support**: Contextual help and support resources
